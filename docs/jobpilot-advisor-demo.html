求职军师：投完不是结束，
看漏斗、给策略、陪你跑完。

大多数找工 agent 把你送到「投出去」就停了。军师多了一层——它看你整个漏斗，先用纯代码算出诊断，再让模型翻成人话建议。下面点一下，看它怎么工作。 关键设计：算账归代码、说话归模型。

为什么这个建议扛得住「你凭什么这么说」

LLM 给求职建议最容易翻车的地方，是它一边编数字一边下结论。军师把这两件事拆开了。

算账 → 归代码

diagnose() 纯确定性，不调 LLM。漏斗、高分岗缺口、停滞天数全用 SQL 算，每个数字都能追溯回一条查询、可测试、不会瞎编。

说话 → 归模型

generate_advice() 才把这些数字喂给 Claude 翻成人话。模型碰不到事实、只碰措辞——它不负责造数据，只负责把诊断说清楚。

还有一条护栏：当几乎没有投递记录时，军师拒绝硬编一套漏斗分析，直接说「先投起来再谈策略」——没有数据的诊断是瞎猜，宁可不给。
